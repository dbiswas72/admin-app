# Admin App

Visit Schedule for a selected trial shows the trial name in the breadcrumb.

`Trials / {trial name} / Visit Schedule`

The trial name comes from the selected trial. Choosing another trial updates the crumb, and the name links to that trial's detail page. The Forms page uses the same breadcrumb styles and `/` separators.

## Run

```bash
npm start
```

Open `http://127.0.0.1:3000/trials/il13xtslp-1b/visit-schedule`.

## Test

```bash
npm test
```
